# 紫のうさぎ — 3D地下駅サバイバルホラー

終電を逃した地下駅「新紫駅」で、展示台から消えた2メートルの紫のうさぎから逃げながら、構内5か所の IC チャージ機で残高 ¥1,000 を貯め、北改札・非常出口から脱出する一人称 3D サバイバルホラーゲームです。

**プレイする:** https://github30.github.io/purple-rabbit-horror/ （ヘッドホン推奨・PC / スマートフォン対応）

## 操作方法

### PC（キーボード / マウス）

| 操作 | キー |
|---|---|
| 移動 | `W` `A` `S` `D` / `↑` `↓` |
| 視点 | マウス（クリックでロック / ドラッグでも可） / `←` `→` |
| ダッシュ | `Shift` |
| しゃがむ | `C` / `Ctrl` |
| 懐中電灯 ON / OFF | `F` |
| チャージ・隠れる・メモを読む | `E` |
| 硬貨を投げて陽動 | `G` / 右クリック |
| 構内マップ | `M` / `Tab` |

### スマートフォン（マルチタッチ）

- **左スティック**: 移動（外周まで倒すとダッシュ）
- **画面ドラッグ**: 視点移動
- **右アクションパッド**: チャージ・隠れる・ライト・しゃがむ・ダッシュ・硬貨・構内図

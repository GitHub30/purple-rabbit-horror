# 紫のうさぎ — 新宿駅 00:47 3Dサバイバルホラー

終電を逃した地下迷宮「JR新宿駅」（アルプス広場・東改札・西口連絡通路・14/15番線階段・B1Fメトロプロムナード）で、展示ケースを破って消えた2メートルの紫のうさぎから逃げながら、構内5か所の Suica チャージ機で残高 ¥1,000 を貯め、東改札・地上出口（歌舞伎町方面）から脱出する一人称 3D サバイバルホラーゲームです。

**プレイする:** https://github30.github.io/purple-rabbit-horror/ （ヘッドホン推奨・PC / スマートフォン対応・開始時自動フルスクリーン＆横画面ロック）

## 主な特徴

- **新宿駅 B1F の地下空間**: アルプス広場のデジタルサイネージ柱、東改札の自動改札機、リアルタイム更新 LED 発車標、山手線 14・15 番線 / 中央線 7・8 番線ホーム連絡階段、NewDays シャッター、acure 自販機、Suica コインロッカー、西口公衆電話ボックス、証明写真機
- **心理的ホラー演出と AI**: サイネージ柱の段階的侵食、柱の陰からの覗き込み（`PEEK_CORNER`）、凝視＋蛍光灯ドミノ破裂、ロッカー／公衆電話ボックスでの**息止め潜伏**、通過する幻影山手線、証明写真機フラッシュ、鳴り響く公衆電話
- **WebGL2 HDR シネマティック描画**: デュアルパス HDR ガウシアンブルーム、深度テクスチャ SSAO、アナモルフィック蛍光灯グレア、CAS シャープニング、ACES フィルムトーンマッピング、動的シャドウ付き懐中電灯

## 操作方法

### PC（キーボード / マウス）

| 操作 | キー |
|---|---|
| 移動 | `W` `A` `S` `D` / `↑` `↓` |
| 視点 | マウス（クリックでロック / ドラッグでも可） / `←` `→` |
| ダッシュ | `Shift` |
| しゃがむ | `C` / `Ctrl` |
| 懐中電灯 ON / OFF | `F` |
| チャージ・隠れる・メモを読む | `E` |
| 息を止める（潜伏中） | `Space` / `B`（長押し） |
| 硬貨を投げて陽動 | `G` / 右クリック |
| 新宿駅構内図 | `M` / `Tab` |

### スマートフォン（マルチタッチ）

- **開始時**: 自動でフルスクリーン・横画面へ移行
- **左スティック**: 移動（外周まで倒すとダッシュ）
- **画面ドラッグ**: 視点移動
- **右アクションパッド**: チャージ・隠れる・息を止める・ライト・しゃがむ・ダッシュ・硬貨・構内図
